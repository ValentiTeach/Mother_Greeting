# Мамо, це тобі — осіння привітальна розгортка

Інтерактивне вітання для мами: розгортка-лист у теплих осінніх тонах
із 3D-анімацією кнопок, листопадом і фотографією в анімованій рамці.

**Відкрити:** просто відкрий `index.html` у браузері — один самодостатній файл,
який працює навіть без інтернету (шрифти й фото вбудовані).

## Що всередині

| Екран | Опис |
|---|---|
| Обкладинка | Сургучева печатка, заголовок «Мамо, це тобі» і кнопка «Відкрити лист» — лист розгортається у 3D |
| Ліва сторінка | Портрет мами в обертовій золотій рамці з листочками на орбіті, підпис і «паспорт» листа |
| Права сторінка | П'ять глав тексту з навігацією, прогресом і фінальною кнопкою «Надіслати обійми» |

### Глави листа

1. **Я тебе дуже люблю і завжди любитиму** — про безумовність цієї любові
2. **Ми всі цінуємо твої старання на роботі** — про працю, яку помічають
3. **Ти все зможеш і в тебе все вийде** — про віру й підтримку
4. **Дякую за все, що ти робиш тихо** — про щоденні дрібниці
5. **Ти в мене найкраща** — побажання й підпис

## Взаємодія

- **Гортання:** кнопки «Далі» / «Назад», крапки-індикатори, стрілки `←` `→`, `Home` / `End`, свайп на телефоні
- **3D-кнопки:** нахиляються за курсором, мають об'ємну грань, блік і «втискаються» при натисканні
- **Освітлення:** перемикач «день / вечір» (тепла світла та темна осінні палітри), вибір запам'ятовується
- **Листопад:** можна зупинити або увімкнути кнопкою вітру
- **Обійми:** кнопка на останній сторінці запускає салют із сердець і листя та рахує надіслані обійми

## Дбайливість до користувача

- Адаптив від 320 px до великих екранів, без горизонтальної прокрутки
- `prefers-reduced-motion` — анімації вимикаються, текст лишається читабельним
- Без JavaScript усі глави показуються одним суцільним листом
- Клавіатурна навігація та видимий фокус, `aria`-підписи для кнопок і сторінок

## Як змінювати

`index.html` збирається з окремих джерел — редагуй їх, а не готовий файл:

```
src/body.html   розмітка й текст листа
src/app.css     стилі, палітри, анімації
src/app.js      навігація, 3D-кнопки, листопад, теми
src/fonts.css   вбудовані шрифти (Cormorant Garamond, Manrope)
Photo/photo     фотографія (JPEG)
```

Після правок перезібрати:

```bash
python3 src/build.py
```

Скрипт підставить фото як data URI та запише новий `index.html`.
